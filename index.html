NotoMarkdown, edited as rendered

A Markdown editor that edits the rendered document and keeps the file byte for byte. No preview pane. You type into headings, tables, task lists, math and fenced code directly.

Byte-exact save

Blocks you did not touch are written back exactly as found, including line endings and whitespace. Open and save without editing and the file is identical to the byte.

Typora-like habits

Edit the rendered document. Source markers appear while you are in a block and fold away when you leave. Cmd+/ opens whole-note source mode.

Vault rail

Open a folder for the workspace tree, outline, quick open, and content search. Recent notes sit in a quiet strip rather than a classic tab bar.

Plugins

Explicit capabilities, two runtimes, and a broker in the main process. Four plugins ship in the build; a template is available for trusted-renderer work.

Remote control

An optional local HTTP API on loopback, token-gated, for scripts and agents on the same machine.

Mac, Windows, Linux

Packaged builds for all three. The current line is 0.0.2-alpha; first-open Gatekeeper and SmartScreen warnings are expected until notarization.
